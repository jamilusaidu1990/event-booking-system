# Build 2 — Event Booking System Backlog

## User Stories

### 1. Search Events
As a customer, I want to search events by name or description
so that I can find events that interest me.

### 2. Filter by City
As a customer, I want to filter events by city
so that I can find events in my preferred location.

### 3. Filter by Date
As a customer, I want to filter events by a date range
so that I can find events happening at a convenient time.

### 4. Filter by Price
As a customer, I want to filter events by minimum and maximum price
so that I can find events within my budget.

### 5. Sort by Date
As a customer, I want to sort events by date
so that I can see earlier events first.

### 6. Sort by Price
As a customer, I want to sort events by price
so that I can compare cheaper events first.

### 7. Sort by Availability
As a customer, I want to sort events by available tickets
so that I can find events with more tickets remaining.

### 8. Automated Testing
As a developer, I want automated tests for search, filters and sorting
so that I can detect bugs when the code changes.
